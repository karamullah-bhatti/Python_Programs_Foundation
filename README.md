# Python Programs Foundation

A collection of foundational Python scripts, exercises, and automation utilities built to master core programming concepts.

## Projects & Utilities

1. **[Caesar Cipher](./Caesar_Cipher/)**
   - **Description:** A text encryption and decryption tool utilizing shift-based ciphers.
   - **Key Concepts:** String manipulation, ASCII codes, loops, and modular arithmetic.

2. **[Number Sequencer](./Number_Sequencer/)**
   - **Description:** A utility for generating, analyzing, and working with custom number sequences.
   - **Key Concepts:** Mathematical logic, loops, lists, and algorithmic thinking.

3. **[Medical-record-Validator](./medical-record-validator/)**
   - **Description:** A script that validates lists of patient records for data types, required keys, and regex pattern matching.
   - **Key Concepts:** `isinstance()`, `re.fullmatch()`, dictionary unpacking (`**`), and error reporting.
