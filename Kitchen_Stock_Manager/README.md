# Kitchen Stock Manager

A Python utility that manages kitchen inventory using custom functions, conditional logic, and state updates.

## Key Concepts Used
- **Function Parameters & Return Values**: Passing data into functions and capturing updated results using `return`.
- **Scope & State Management**: Updating global/local state by reassigning function outputs to variables.
- **Conditional Logic**: Using boolean checks (`>=`) to control program flow and execution.

## How to Run
```bash
python kitchen_stock.py
